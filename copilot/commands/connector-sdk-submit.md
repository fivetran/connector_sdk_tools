---
description: Prepare a Fivetran Connector SDK contribution for a pull request
argument-hint: "Connector directory name or path (e.g., 'github_connector' or './github_connector')"
---

Invoke the `connector-sdk-submit` skill from this plugin to prepare a Connector SDK contribution for submission. The skill selects the appropriate upstream repository, applies Community Connectors submission rules, sanitizes tracked configuration, validates documentation, formats and lints code, and guides the contributor through the pull-request handoff.

User request: $ARGUMENTS
